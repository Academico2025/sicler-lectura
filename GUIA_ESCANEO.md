# Cómo escanear SICLER

1. Publica la carpeta completa en GitHub Pages (HTTPS).
2. Abre el sitio en Chrome o Safari del celular.
3. Pulsa **Explorar una tarjeta con mi cámara** y acepta el permiso.
4. Acerca un marcador de color impreso: **verde**, **azul** o **morado**. La aventura se abre automáticamente.
5. Si prefieres, toca la tarjeta desde `tarjetas.html` o elige un mundo.

**Aviso:** la cámara nativa del teléfono no puede reconocer estas figuras como enlaces. Para abrir la web desde la cámara nativa necesitarías tarjetas con códigos QR que contengan la URL real de GitHub Pages.

Los tres colores activan tres mundos, no distinguen individualmente a los diez estudiantes.

Para confirmar la publicación después de cargar los archivos, usa una ventana privada o borra los datos del sitio de la versión anterior, porque los navegadores pueden retener recursos antiguos.

Las animaciones son superposiciones 2D con profundidad simulada, no modelos 3D anclados al marcador.
